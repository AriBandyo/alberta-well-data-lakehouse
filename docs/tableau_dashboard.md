# Tableau dashboard guide

Use `tableau/data/public_municipality_energy_summary.csv` as the primary data source.

Recommended worksheets:

1. Oil production by municipality
2. Natural gas production by municipality
3. Reported well count by municipality
4. Year-over-year production momentum
5. Energy activity score ranking
6. Oil and gas volume per reported well
7. Data-quality status

Recommended dashboard filters:

- Municipality
- Activity class
- Metric availability
- Positive or negative year-over-year change

The included `tableau/dashboard_preview.html` provides an immediate browser-based view of the generated results. It is not a Tableau workbook; it is a local review artifact built from the same gold output used for Tableau extracts.
